# Vagus v0.1.0-beta.4

<!-- Release date: 2026-10-13 -->

This beta improves discovery of Agent command-line tools installed outside the desktop app's inherited `PATH`.

## Added

- Show the resolved Agent executable path and how it was found in the model catalog settings.

## Improved

- Find local Agent CLIs through the app `PATH`, the macOS login shell, common per-user install locations, and platform search indexes.
- Detect Claude Code installed through VS Code, VS Code Insiders, or Cursor extensions.
- Pass the expanded executable search path to Agent processes so command shims can locate their runtime dependencies.
- Show the underlying catalog refresh error when Vagus keeps displaying cached models.

## Fixed

- Resolve local Pi, Claude Code, Codex, OpenCode, Qoder CLI, and ZCode executables to absolute paths before launching them.

## Known issues

- macOS installers are unsigned and have not been notarized. macOS may show a security warning before the app can be opened.
- macOS packages have not completed release-level validation. Windows x64 is the primary beta target; Linux is not supported.
- Node.js 22.13 or later and the desired agent CLIs must be installed and configured separately. ZCode integration requires the community-maintained `zcode-acp-server`.
