# Vagus v0.1.0-beta.2

<!-- Release date: 2026-10-13 -->

This beta improves local Agent discovery and the macOS desktop experience.

## Added

- Discover Claude Code when it is installed through the VS Code, VS Code Insiders, or Cursor extension.

## Improved

- Find Claude Code and Codex installed in the macOS login-shell PATH when Vagus is launched from Finder.
- Use native macOS window controls in the same row as the Vagus toolbar.
- Sharpen hover tooltips and use the platform system font across desktop platforms.

## Fixed

- Show the correct `codex` executable setting hint on macOS.

## Known issues

- macOS installers are unsigned and have not been notarized. macOS may show a security warning before the app can be opened.
- macOS packages have not completed release-level validation. Windows x64 is the primary beta target; Linux is not supported.
- Node.js 22.13 or later and the desired agent CLIs must be installed and configured separately. ZCode integration requires the community-maintained `zcode-acp-server`.
