# Vagus v0.1.0-beta.6

<!-- Release date: 2026-10-14 -->

This beta adds previews for local images referenced in Markdown and refines the provider catalog.

## Added

- Open local images referenced in conversations in a dedicated workspace preview.

## Improved

- Refine provider catalog controls and executable path status display.

## Fixed

- None.

## Known issues

- macOS installers are unsigned and have not been notarized. macOS may show a security warning before the app can be opened.
- Codex discovery may fail on macOS when the system index resolves an incompatible executable instead of the installed Codex CLI.
- macOS packages have not completed release-level validation. Windows x64 is the primary beta target; Linux is not supported.
- Node.js 22.13 or later and the desired agent CLIs must be installed and configured separately. ZCode integration requires the community-maintained `zcode-acp-server`.
