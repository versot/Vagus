# Vagus v0.1.0-beta.5

<!-- Release date: 2026-10-13 -->

This beta makes it easier to connect local coding agents and improves Windows installer branding.

## Added

- Show platform-specific installation commands and setup guidance when an Agent has no available models.
- Link each setup guide to the Agent's installation documentation. ZCode's guide identifies its community-maintained ACP connector and explains that ZCode must also be installed and signed in separately.

## Improved

- Use the Vagus application icon in the Windows NSIS installer and uninstaller.

## Fixed

- None.

## Known issues

- macOS installers are unsigned and have not been notarized. macOS may show a security warning before the app can be opened.
- macOS packages have not completed release-level validation. Windows x64 is the primary beta target; Linux is not supported.
- Node.js 22.13 or later and the desired agent CLIs must be installed and configured separately. ZCode integration requires the community-maintained `zcode-acp-server`.
