# Vagus v0.1.0-beta.1

The first public beta of Vagus brings local coding agents into one desktop workspace. Start or resume conversations, follow agent activity as it happens, and review file changes alongside each turn.

## Added

- Start conversations with Pi, Claude Code, Codex, OpenCode, Qoder CLI, and ZCode using their locally installed tools.
- Organize conversations by project, search past sessions, and import supported agent history.
- Inspect tool activity, execution status, changed files, and turn-by-turn diffs in the desktop workspace.
- Open file, terminal, browser, and review tabs while working with an agent.
- Schedule local tasks with an available agent, model, and working mode.

## Improved

- Keep each agent's selected model, thinking level, and working mode available across new conversations where supported.
- Provide light and dark themes and multiple interface languages.

## Known issues

- macOS installers are unsigned and have not been notarized. macOS may show a security warning before the app can be opened.
- macOS packages have not completed release-level validation. Windows x64 is the primary beta target; Linux is not supported in this release.
- Node.js 22.13 or later and the desired agent CLIs must be installed and configured separately. ZCode integration requires the community-maintained `zcode-acp-server`.
