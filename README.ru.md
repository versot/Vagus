## Рабочее пространство для агентов-разработчиков

Vagus объединяет проекты и диалоги с агентами в одном настольном приложении. Выбирайте агента, следите за его работой, изучайте изменения файлов рядом с диалогом и возвращайтесь к предыдущим сеансам. CLI агентов, учётные записи и модели по-прежнему настраиваются на вашем компьютере.

## Возможности

- **Выбирайте агента под задачу.** Используйте Pi, Claude Code, Codex, OpenCode, Qoder CLI или ZCode в одном проекте с моделями и режимами, доступными через соответствующую интеграцию.
- **Следите за процессом.** Просматривайте ответы по мере появления, вызовы инструментов и состояние выполнения прямо в диалоге.
- **Проверяйте изменения в контексте.** Смотрите изменённые файлы для каждого шага и открывайте полный diff рядом с диалогом.
- **Держите инструменты под рукой.** Открывайте вкладки файлов, терминала, браузера и проверки изменений в рабочем пространстве.
- **Возвращайтесь к прошлой работе.** Ищите диалоги и импортируйте собственную историю агентов, которые это поддерживают.
- **Планируйте повторяющиеся задачи.** Создавайте локальные задания по расписанию, выбирая доступного агента, модель и режим.

### Интегрированные агенты

| Агент | Интеграция | Примечания |
| --- | --- | --- |
| Pi | Pi RPC | Поддерживаются расширения Pi и импорт нативной истории диалогов. |
| Claude Code | Мост ACP | Установка, вход и настройки управляются локальной CLI Claude Code. |
| Codex | Codex app-server | Используется локальная CLI Codex; app-server пока является экспериментальным интерфейсом. |
| OpenCode | ACP | Используются возможности сессий, предоставляемые локальной CLI OpenCode. |
| Qoder CLI | ACP | Используются возможности, предоставляемые локальной CLI Qoder. |
| ZCode | Мост ACP | Подключение через поддерживаемый сообществом `zcode-acp-server`; это не официальная ACP-интеграция Z.ai. |

Официальные инструменты каждого агента отвечают за установку, учётную запись и настройки моделей.

## Поддерживаемые платформы

Vagus находится на этапе публичного бета-тестирования. Первый релиз включает установщики для Windows x64, macOS Intel и Apple silicon. Подпись кода и нотариальное заверение macOS не настроены, а пакеты для macOS ещё не прошли проверку перед выпуском. Linux пока не поддерживается. Наличие сборки не означает, что совместимость проверена.

## Бета-версии и загрузки

Первую публичную тестовую версию можно скачать на странице [Vagus v0.1.0-beta.1](https://github.com/versot/Vagus/releases/tag/v0.1.0-beta.1). На странице каждого GitHub Pre-release размещены установщики, описание изменений и известные проблемы. Перед тестированием сохраните важные данные, а при сообщении об ошибке укажите версию Vagus и операционную систему.

Настольное приложение запускает Vagus Host с помощью локального Node.js и требует Node.js 22.13 или новее. Необходимые CLI агентов пользователь устанавливает, настраивает и авторизует самостоятельно. Установщики не содержат Node.js и CLI агентов.

Для каждой версии в каталоге [`releases/`](releases/) хранится отдельный Markdown-файл с описанием изменений; этот же файл используется как текст GitHub Release.

### Требования

- 64-разрядная Windows
- Node.js 22.13 или новее и npm
- Rust stable, средства сборки MSVC C++ и Windows SDK
- Microsoft Edge WebView2 Runtime

Запустите приложение для разработки из корня репозитория:

```powershell
npm ci
npm run dev
```

Сборка настольного установщика:

```powershell
npm run build:desktop
```

### Проверка изменений

```powershell
npm run test:stage-one
npm run build:app
cargo test --locked --manifest-path packages/desktop/src-tauri/Cargo.toml
```

Автоматические проверки качества сейчас выполняются в Windows CI. Успешный CI не означает, что все версии агентов, конфигурации компьютеров и платформы прошли сквозную проверку. См.
