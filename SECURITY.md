# Security Policy

Vagus is currently in Beta. Security fixes are handled on a best-effort basis; no response or remediation timeline is guaranteed.

## Supported versions

Please report vulnerabilities against the latest Beta release or the current `main` branch. Older releases may not receive fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when it is enabled. If it is unavailable, contact a repository maintainer through a private contact channel listed on their GitHub profile. Do not open a public issue or include exploit details in a public discussion before maintainers have had a reasonable opportunity to investigate.

Include the affected version or commit, the impacted component, steps to reproduce, and any known impact. Do not include real user data, credentials, or secrets in a report.
